AQuA source-data discrepancy report

28 October 2026 · 354 affected records · 304 distinct exact question texts

Scope: Google DeepMind AQuA public dataset at commit 26b64ed1f22208c6742f47df547dfd65088ec30d. This is a bounded audit of selected question patterns and explicit rationale equations, not a full quality estimate or a reproduction of the original paper's results.

  • 121 question/answer-key discrepancies, including missing correct options. Selected published values differ by over 10% from the calculation under the question's standard interpretation.
  • 223 explicit arithmetic discrepancies in rationales. These establish a false numeric equality as printed, not necessarily a wrong final answer key; some are transcription errors.
  • 10 independently calculated key/conclusion conflicts. These include wrong answer keys and rationales naming the wrong answer option.

Fifty additional occurrences repeat an exact question text and are marked below. They are affected source records, not fifty additional distinct questions. Near-duplicate wording, renamed variables, shared templates and common root causes may further reduce the number of independent problems. This is not a claim of 354 independent bugs, 354 wrong answer keys, or author-accepted corrections.

Evidence: selected original records, source-line URLs, whole-source SHA-256 and Git blob hashes, exact-fraction calculations, a standard-library reproduction script, review exclusions, and independent second-pass results are bundled. Run python reproduce.py in the extracted evidence folder. Source bytes were checked against GitHub's pinned tree; every selected record was reread from those bytes. Arithmetic was independently checked with SymPy as well as the bundled exact evaluator.

Selection exclusions include units-digit shortcuts, clock/base arithmetic, plausible lost fractions or superscripts, proportional shorthand, ambiguous profit/interest wording, and the already-reported test.json line 153 issue. Targeted prior-mail and public issue searches found no matching report for this selected batch; that does not establish novelty everywhere. Tokenized mirrors were not counted as new findings.

The repository README explains that the publicly released dataset differs from the unreleased version used for initial published results. We therefore make no inference about the original paper's reported accuracy or any model ranking. The dataset is crowdsourced, and repository hosting does not imply Google staff authored each annotation.
